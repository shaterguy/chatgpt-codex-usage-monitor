# Codex Usage Bar

ChatGPT 웹 화면에서 현재 로그인된 계정의 Codex 사용량을 확인하는 Chrome Manifest V3 확장 프로그램입니다. 기본적으로 ChatGPT 우상단 헤더에 사용량 캡슐을 통합하며, 캡슐에는 잔여량 막대와 ChatGPT 웹의 전체 상태가 항상 함께 표시됩니다. 캡슐을 누르면 5시간 한도·주간 한도·리셋 시각·추가 크레딧·서비스별 상태가 팝오버로 열립니다.

## 설치

1. 배포 ZIP 파일의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions/`를 입력합니다.
3. 오른쪽 위의 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
5. 압축을 푼 `codex-usage-bar` 폴더를 선택합니다.
6. 로그인된 상태로 [ChatGPT](https://chatgpt.com/)를 새로고침합니다.

## 헤더 통합과 사용법

- ChatGPT 헤더 구조를 확인해 요금제 버튼과 새 채팅 버튼 사이에 사용량 캡슐을 삽입합니다.
- 캡슐에는 5시간 잔여량, 막대, ChatGPT 웹 전체 상태가 접힌 상태에서도 표시됩니다.
- 캡슐을 누르면 5시간·주간 사용량, 리셋 시각, 추가 크레딧과 서비스별 상태가 팝오버로 열립니다.
- 팝오버의 새로고침 버튼으로 즉시 다시 확인할 수 있습니다.
- 설정 버튼에서 자동 확인 주기를 30초, 60초, 2분 또는 5분으로 바꿀 수 있습니다.
- ChatGPT가 화면을 다시 그리더라도 헤더를 감시해 캡슐을 자동으로 재삽입합니다.
- 헤더를 찾을 수 없는 화면에서는 이동 가능한 위젯으로 자동 전환되고, 헤더가 돌아오면 다시 통합됩니다.
- 이동형 대체 모드에서는 위젯을 드래그하거나 방향키로 10픽셀씩, Shift+방향키로 1픽셀씩 이동할 수 있습니다. 위치는 자동 저장됩니다.

## 초기화권

- 5시간 한도의 잔여량이 5% 이하이고 초기화권이 있으면 확인 팝업을 한 번 표시합니다.
- `나중에 (30분 후)`를 누르면 같은 리셋 창의 알림을 30분 동안 보류하며, 자동 확인이 반복되어도 그 전에 다시 표시하지 않습니다.
- `0%까지 알리지 않기`를 누르면 표시 잔여량이 0%가 될 때까지 같은 리셋 창의 자동 알림을 억제하고, 0%에 도달하면 다시 한 번 확인합니다.
- 상세 화면에서도 `초기화권 사용` 버튼을 눌러 확인 팝업을 열 수 있습니다.
- 팝업의 `초기화권 사용`을 다시 눌러야 실제 사용 요청이 전송됩니다. 확장 프로그램이 초기화권을 자동으로 소비하지는 않습니다.
- 결과는 팝업 안에 표시되며, 성공한 뒤 사용량과 초기화권 수를 다시 확인합니다.

초기화권 사용은 되돌릴 수 없는 계정 작업입니다. 버튼을 누르기 전에 표시된 잔여량과 보유 수량을 확인해 주세요.

## ChatGPT 웹 상태

접힌 헤더 캡슐에는 ChatGPT 웹의 전체 상태가 사용량과 함께 항상 표시됩니다. 캡슐을 누르면 OpenAI 공식 상태 데이터에서 다음 ChatGPT 웹 관련 항목만 상세 목록으로 보여 줍니다.

- 로그인
- 대화
- ChatGPT Work
- 파일
- 검색
- 연결 앱
- GPTs
- 이미지 생성
- 에이전트
- Sites
- Codex Web

Codex API, 일반 API, Batch, CLI, IDE 확장, 데스크톱 앱 등 ChatGPT 웹 사용과 직접 관련 없는 상태는 요약과 목록에서 제외합니다.

## 준실시간 갱신

다음 시점에 사용량을 다시 확인합니다.

- ChatGPT 페이지에 처음 진입했을 때
- 응답 생성이 끝난 것으로 감지됐을 때
- 프롬프트를 전송한 뒤의 보조 확인 시점
- 다른 탭에서 ChatGPT 탭으로 돌아왔을 때
- 설정한 자동 확인 주기가 도래했을 때
- 사용자가 새로고침 버튼을 눌렀을 때
- 첫 조회가 실패하거나 지연됐을 때의 짧은 자동 복구 시점

응답 완료 감지는 ChatGPT의 특정 CSS 클래스 하나에 의존하지 않고, 답변 영역 변화와 생성 중지 버튼의 상태 전환을 함께 사용합니다.

## 데이터와 권한

- 동작 범위는 `chatgpt.com`과 이전 주소인 `chat.openai.com`으로 제한됩니다.
- 공개 상태 확인을 위해 `status.openai.com`의 공식 상태 요약만 읽습니다. 계정 정보나 사용량을 그 서버로 전송하지 않습니다.
- API 키, 로그인 쿠키 또는 액세스 토큰을 확장 프로그램 저장소에 보관하지 않습니다.
- ChatGPT 페이지가 현재 세션으로 읽을 수 있는 Codex 사용량 응답만 화면에 표시합니다.
- 저장하는 정보는 이동형 대체 모드의 위치, 펼침 상태, 자동 확인 주기, 30분 보류 시각과 현재 리셋 창의 0%까지 알림 억제 여부뿐입니다.

## 사용량 데이터 호환성

2026-07-15 기준 OpenAI 공식 Codex 클라이언트가 ChatGPT 웹에서 사용하는 `/backend-api/wham/usage` 경로와 `primary_window`, `secondary_window`, `used_percent`, `reset_at`, 크레딧 및 추가 한도 필드를 지원합니다. 쿠키 요청과 현재 세션의 메모리 내 인증 요청을 자동 전환하며, 개별 요청이 멈춰도 다음 방식으로 넘어가도록 타임아웃을 적용했습니다. snake_case와 camelCase 응답을 모두 처리합니다.

OpenAI가 내부 사용량 또는 초기화권 응답을 변경하면 확장 프로그램도 업데이트가 필요할 수 있습니다. 이 경우 펼친 화면의 `공식 화면`을 눌러 [Codex Analytics](https://chatgpt.com/codex/cloud/settings/analytics)를 확인할 수 있습니다.
